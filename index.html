ぴこもり — 切り抜き制作ツール

配信アーカイブから場面を選び、テロップを焼き込んだ動画を作って、運営者自身の YouTube チャンネルへ投稿する個人用のツールです。

プライバシーポリシー 利用規約 チャンネル

このツールについて

公開されている配信アーカイブから見どころの場面を選び、話された言葉を全文テロップとして焼き込んだ動画を組み立てます。 できあがった動画は、運営者が所有する YouTube チャンネル ぴこもり【にじさんじ切り抜き】 へ非公開で投稿され、運営者が内容を確認してから公開されます。

利用者は運営者本人のみです。一般に配布しておらず、他の利用者を受け入れる仕組みもありません。

YouTube API の利用

本ツールは YouTube Data API v3 を利用し、運営者自身のチャンネルに対してのみ次の操作を行います。

  • 動画のアップロード（既定は非公開）
  • サムネイルの設定
  • 再生リストの作成と追加
  • 自分が投稿した動画の公開状態の確認と変更

他者のチャンネルを操作することはありません。取り扱うデータについては プライバシーポリシーをご覧ください。
